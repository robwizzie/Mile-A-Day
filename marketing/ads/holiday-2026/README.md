# Holiday 2026 paid ads (Meta: Instagram + Facebook)

Plan: "Mile A Day Holiday Ad Plan: Thanksgiving + New Year" (Claude doc). Campaigns are judged on cost per new user who
logs their first mile, not cost per install.

## Layout system

Every ad follows the same layout, so the set reads as one brand and each ad says one thing:

- App Store colour background, centred kicker, two-line headline and one sentence in the top band.
- A large real phone, centred, bleeding off the bottom edge.
- ONE real UI element cropped from that same screen and lifted out at about 1.5× so the feature reads at a glance.
- Streak screens show 37 days rather than the 541 in the App Store screenshot: a reachable number reads better to someone on day zero. The stats card is redrawn in the app's style for that.
- No stickers or extra characters. Flamey appears only where he is on the real screen.
- Voice: we call ourselves streakers, and the copy invites people to become one. Meta shows the app name and a
  Download button under the image, so the image carries no button of its own.
